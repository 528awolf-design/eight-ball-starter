# Magic 8 Ball
This is a Magic 8 Ball website! Simply ask it anything. Some say it knows everything.
## Project Overview
A Magic 8 Ball is a toy which displays a multitude of different answers based on a simple shake. This project allows me to redesign this concept in a website format, albeit limited in responses. I have added a skin to my 8 Ball, as it is now a yellow circle with a smiley face. 
## Design Decisions
I decided to make my 8 Ball a smiling yellow orb since I knew I could make an interesting theme out of it. My design uses color to draw attention into the 8 Ball, while also using white space to detract attention from the sides. My website also uses many rounded shapes, especially squares, to give it a functional feel.
## My Answers
| Yes Answers | No Answers | Maybe Answers |
| ----------- | ---------- | ------------- |
| Without a doubt. | I doubt it. | Cannot predict now. |
| I would! | My reply is no. | Click again? |
| Outlook good. | I wouldn't do that if I were you... | N/A |
## My Answer Types
I have three answer types; Yes, No, and Maybe. In the code, numbers 0-2 are Yes values, 3-5 are No values, and 6-7 are Maybe values. The number 8 is assigned to ???, which triggers if the user does not enter a question.
